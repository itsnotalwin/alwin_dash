# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User delegated the recommendation on 20 October 2026: lightweight Node.js server, plain HTML/CSS/JavaScript client, no runtime packages. User selected an image concept before implementation.

## Users
Alwin, checking daily priorities, relocation plans, creative projects for Paige, and personal goals.

## Product Purpose
Provide a daily action view derived from the existing private BRAIN vault. Keep source notes authoritative and show source dates, blockers, and next actions.

## Operating Context
The requested source repository is public. Never commit real vault contents, access tokens, financial balances, contact details, or private screenshots. Private note reads and version-checked task changes happen only on an authenticated server.

## Capabilities and Constraints
Today leads. Dedicated Australia, For Paige, My life, and Brain views. Automatic refresh while open. Read only an explicit list of canonical notes. Preserve unknown states and dated research. Write task completion and new tasks to the selected canonical source, with SHA conflict protection.
The monochrome build is approved. The user-selected visual reference establishes expressive display typography, organic dividing geometry and rounded pale working surfaces in the grayscale system. Hosted deployment uses owner-private Sites sign-in; standalone Node hosting retains the password/session flow. The runtime vault credential is still required for live BRAIN access. Sample mode is explicit and cannot write.

## Product Principles
- A clear next action comes first.
- Every imported action has a source and source version.
- Plans and research are not evidence of achieved progress.
- BRAIN remains the permanent source of truth.
- Show failures and stale data explicitly.
