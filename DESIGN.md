# Visual system
A personal daily planner in Operate mode. User-requested monochrome palette (20 October 2026): charcoal rail #1b1b1b, off-white canvas #f3f3f3, white work surfaces, graphite emphasis #262626, muted text #626262 and rules #d8d8d8. All interaction, status, focus, form and browser colors use neutral shades. System sans body, Georgia display, 8/12/16/24/32 spacing, restrained 6–12px corners.
Today presents source-backed actions before the bigger move picture. Domain pages reveal more detail without implying progress. Source text is plain text in a native dialog. Dates always distinguish source update and read time. The concept’s sample destination labels were generalized in code until sourced; no private facts were copied into fixtures.
