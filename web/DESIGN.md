# Dashboard design
Operate mode. User-requested monochrome treatment: charcoal left rail, off-white canvas, white working surfaces and graphite emphasis. Georgia headings add a personal editorial character; system sans text keeps controls fast to scan. Tokens: ink #1b1b1b, muted #626262, canvas #f3f3f3, accent #262626, rule #d8d8d8. Tags, states, focus rings, selection, form controls and favicon are neutral; labels preserve status meaning. Corners 6–12px, thin borders, no gradients. Spacing 8/12/16/24/32px.
Today leads with actionable checkboxes beside a destination panel; a dated milestone row follows; project and life sections use rows instead of decorative metrics. Mark source facts as recorded and show source dates. No inferred completed migration stages or manufactured savings figures.
At 1000px, reduce the rail; below 760px, use a sticky horizontal navigation and one content column. Minimum targets 44px; visible focus rings; native dialogs; reduced-motion support; no information relies on color alone. All imported note content uses textContent.
