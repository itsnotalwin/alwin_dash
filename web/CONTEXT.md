# Dashboard client

Authenticated monochrome daily planner with Today, Australia, For Paige, My life and Brain views. `index.html` owns the semantic shell, organic divider and native dialogs. `app.js` renders source projections with DOM text, local focus stars, readable Markdown tables, searchable source coverage and version-checked task edits. `style.css` owns the reference-based grayscale system and bounded interaction motion and the two-contour liquid divider. app.js owns its visibility-aware 30fps loop and persistent pause control. Root DESIGN.md is the token authority; OFL-Lobster.txt licenses the embedded font.

Twenty-two allowlisted notes are fetched only through the same-origin API. Reference checklists remain readable but do not become daily actions. No private note content, credentials or live captures belong in this public repository. Preview/CI use demo.mjs only. Owner-private Sites authentication and the read-only runtime remain unchanged. Refresh occurs on opening, every five minutes while visible, and on return; this does not discover new vault files or reverify claims.

Verify with npm run check, npm test, npm run build and verify-ui.mjs in CI. Cover search/filter, stars across source revisions, all five views, native source dialog/tables, keyboard focus, 320/390/768/1440 widths, reduced motion, liquid geometry changes, pause persistence and offscreen suspension. Maintain genuine synthetic desktop/mobile captures and their dates in DESIGN.md. entry.html remains the standalone GitHub Pages redirect.
